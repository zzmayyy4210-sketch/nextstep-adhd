# 小步 · NextStep 🌱

**为 ADHD、容易分心和任务启动困难的人设计的中文任务助手：把压得人喘不过气的大任务，变成现在就能做的小动作，一次只执行一步。**

<p align="center"><a href="https://nextstep-small-steps-4210.zzmayyy4210.chatgpt.site"><strong>🌱 点击这里，立即在线体验 →</strong></a></p>

手机和电脑都能打开；不注册、不填 API，也能先体验完整的基础流程。

## 为什么做这个项目

有时候，难的不是不知道任务重要，而是不知道从哪里开始。长清单和催促很难帮人迈出第一步。

小步希望降低启动门槛：先打开一本书、拿起一个袋子，或只写一句话。一次只显示当前动作；太难就继续拆小，累了可以休息，回来接着做。没有连续打卡惩罚，也不因进度缓慢而责备使用者。

这是日常任务组织工具，不是 ADHD 诊断或治疗工具。

## 30 秒体验

1. [打开体验页面](https://nextstep-small-steps-4210.zzmayyy4210.chatgpt.site)。
2. 输入“整理房间”，或点击示例，选择当前精力。
3. 点击“帮我找到第一步”，只做眼前的小动作。
4. 做完点击“这一步，完成了”；卡住点击“再拆小一点”。

支持倒计时、暂停、撤回、完成反馈、任务历史、本机保存和导出。支持的安卓浏览器可以添加到主屏幕；目前是网页/PWA，不是 APK。

## 免费与费用：谁的 API，谁的账号

| 模式 | 密钥 | 模型费用 |
| --- | --- | --- |
| 免费基础体验（默认） | 不需要 | 不调用模型，没有模型调用费 |
| 自己的 OpenRouter API | 使用者自己的密钥 | 固定调用 openrouter/free，不自动转付费；受平台免费额度与可用性限制 |
| 自定义兼容接口 | 使用者自己的密钥、地址和模型 | 按使用者自己的服务商账号计费，请自行确认价格 |

**公开版没有作者的共享密钥，没有替他人垫付模型费用的后端。** 未启用个人 API、额度耗尽、接口失败或输出格式错误时，仍可使用基础规则拆分。基础模式使用本机任务模板，不会冒充大模型。

项目不收费，不会自动购买、充值、订阅或升级任何服务。自行部署时，托管商有各自的额度或计费规则；请使用其免费方案，不启用付费升级。

## 使用自己的 API

打开网页右上角 **“使用自己的 API”**：

1. 勾选“启用我自己的 API”。
2. 选择 OpenRouter，填写自己账户的专用 API Key，点击“应用设置”。默认仅使用免费路由。
3. 回到页面新建任务，或对当前步骤点击“再拆小一点”。

密钥只保留在当前页面内存，刷新或关闭后需重新填写；可点击“断开并清除密钥”。密钥不存入 localStorage、任务导出、项目服务器或 GitHub。请求由浏览器直接发送到使用者选择的服务商，任务和密钥会传给该服务商，受其数据政策约束。建议使用设有额度上限、可随时撤销的专用密钥。

高级用户可填写完整的 HTTPS `/chat/completions` 地址、模型名称/接入点 ID 和密钥。接口必须支持 Chat Completions 及浏览器跨域访问（CORS）；**并非所有服务商都允许网页直连**。例如豆包等接口若不允许跨域，需使用者自己部署兼容网关。不要使用不信任的代理，密钥会发送到所填地址。项目不提供公共代理。

没有真实密钥时，验证使用模拟响应，不代表已实测某个账户或所有服务商。

## 本机运行

需要 Node.js 20 或更新版本，无需安装依赖：

```sh
npm start
```

打开 `http://localhost:3000`。也可用任意静态托管服务部署 `public/`，个人 API 不需要项目后端。

## 部署

- **GitHub Pages**：Settings → Pages → Deploy from a branch → `main` → `/docs`。`docs/` 是 `public/` 的镜像，支持基础体验和个人 API。
- **Vercel**：导入仓库，选择 Other；仓库配置发布纯静态页面，无共享密钥和模型代理。
- **其他静态托管**：发布 `public/`，HTTPS 下支持 PWA 离线基础模式。

任务保存在当前设备的 localStorage，最多保留最近 30 个任务；没有跨设备同步或后台追踪脚本。共享网址不会共享本机任务。首次在线访问后可以离线使用基础模式，个人 AI 需要联网。

## 开发与验证

